# **App Name**: iFrame Manager

## Core Features:

- User Registration and Login: Users can create accounts, log in securely, and manage their profiles.
- iFrame Display: Display user-specific iFrames based on assignments in the backend.
- Admin User Overview: Backend interface providing an overview of all registered users.
- iFrame Assignment: Backend functionality to assign specific iFrames to individual users.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a professional and trustworthy feel.
- Background color: Light gray (#F5F5F5) to ensure content readability and a clean interface.
- Accent color: Teal (#009688) to highlight important actions and elements, providing a modern touch.
- Body and headline font: 'Inter' (sans-serif) for clear, accessible text, ensuring readability and a modern, neutral aesthetic.
- Clean and organized layout with a focus on usability and intuitive navigation.
- Use clear, simple icons to represent different functionalities and iFrame sources.
